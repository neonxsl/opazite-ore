# Opazite

The Opazite Ores mod adds a brand new, magical, crystal ore, Opazite!

## Where to find them?

Opazite is only found below y=0, so only a deeplsate variant exists..
You also must have a Diamond or higher pickaxe to mine both the ore and the block

The ore drops one Opazite gem (is increased with Fortune)

## What is it?

It acts as a perfect mediary to Diamond and Netherite, its more better and more durable than Diamond, yet not as powerful and rare as Netherite!

## What's added?

The mod adds all tools (sword, axe, pickaxe, hoe, shovel) as well as armour, it also adds the Block of Opazite, which is crafted much like the other Block of Ores, 9 opazite gems in the crafting grid
